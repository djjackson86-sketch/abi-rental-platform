# POPIA document pack — manifest

The single source of truth for the POPIA document pack (feature Q, §Q1): the
documents Sano can adopt in the app, their human titles, files, and whether
adopting one is a signature (a contract) or a plain "adopted" record.

**The pack order lives here**, not in templates: the app renders the pack in the
order of the table below, so a fifth document is added here and nowhere else.

A missing file is reported by the app, never invented.

| Key | Title | File | Signature required |
| --- | --- | --- | --- |
| privacy_notice | Privacy Notice | PRIVACY-NOTICE.md | no |
| retention_policy | Retention Policy and Schedule | RETENTION-POLICY-AND-SCHEDULE.md | no |
| action_plan | POPIA Compliance Action Plan | POPIA-COMPLIANCE-ACTION-PLAN.md | no |
| operator_agreement | Operator Agreement (ABI Solutions ↔ Sano Trailers) | OPERATOR-AGREEMENT-ABI-SANO.md | yes |
